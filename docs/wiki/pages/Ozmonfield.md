The Ozmonfield (オズモーネ平原, Ozumōne Heigen?) is a location in Final Fantasy Tactics Advance. It is a version of the Ozmone Plain that appears in Final Fantasy XII. Though both games are set in the same world of Ivalice, the Final Fantasy Tactics Advance Ivalice is in fact a dream world version of the world in Final Fantasy XII, and so some place names are bound to be similar, but not exactly the same. Ozmonfield is unlocked after "Mission #066: Dargon's Aid" is completed and is the site of "Mission #090: Clan Law". It can be freed in "Mission #263: Ozmonfield" after the main game is cleared.
